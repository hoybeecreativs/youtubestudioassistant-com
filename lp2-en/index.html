Frequently Asked Questions (FAQ)

How much does this extension cost?

You can try all features for FREE for 7 days. After that, upgrade to a lifetime license (one-time payment, forever access). Some AI providers like Pollinations.ai are also 100% free without an API key.

What AI providers are supported?

We support 6 AI providers: Pollinations.ai (100% free, no API key), Groq (free & super fast), OpenRouter (many free models), Google Gemini (free tier available), OpenAI (best quality, GPT-4o), and DeepSeek (most affordable paid option). You can switch anytime.

Is my video data safe?

Yes, 100% safe. We don't store your video content or API keys on our servers. All processing is done directly in your browser.

How many languages are supported?

Over 110 languages! You can translate titles, descriptions, and tags to all languages supported by YouTube automatically.

Can I use this on a mobile phone (Android/iOS)?

Currently, the extension can only be used on a PC or Desktop using the Google Chrome browser (or Chromium-based browsers like Edge, Brave, etc.). YouTube Studio Assistant does not yet support mobile usage (phones/tablets).
