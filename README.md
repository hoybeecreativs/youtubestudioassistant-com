# YouTube Studio Assistant Website

Official website for YouTube Studio Assistant - AI-powered content generation and translation tool for YouTube creators.

## 🌟 Features

- **Modern Design**: Clean, responsive design with orange gradient theme
- **Netlify CMS**: Easy content management without coding
- **Contact Form**: Built-in form with Netlify Forms integration
- **SEO Optimized**: Meta tags, semantic HTML, and fast loading
- **Mobile Responsive**: Works perfectly on all devices

## 🚀 Tech Stack

- **HTML5 & CSS3**: Modern, semantic markup
- **JavaScript**: Vanilla JS for interactions
- **Netlify CMS**: Content management system
- **Netlify Forms**: Form handling
- **Git**: Version control

## 📁 Project Structure

## 🎨 Design

- **Color Scheme**: Orange gradient (#ff6b35 to #f7931e)
- **Typography**: Inter font family
- **Layout**: Grid-based, responsive design
- **Components**: Cards, buttons, forms, navigation

## 📝 Content Management

Access the CMS at: `https://youtubestudioassistant.com/admin/`

You can edit:
- Pages (About, etc.)
- Team members
- Features
- Site settings

## 🔧 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/hoybeecreativs/youtubestudioassistant-com.git
   ```

2. Open `index.html` in your browser

3. For CMS testing, deploy to Netlify first

## 📦 Deployment

This site is deployed on Netlify with automatic deployments from the `main` branch.
