Claude Integration

How YouTube Studio Assistant uses the Anthropic Claude API

Overview

YouTube Studio Assistant is a Chrome extension, available on the Chrome Web Store, that adds AI panels directly inside YouTube Studio. Anthropic Claude is one of the 9 AI providers creators can select in the extension settings.

When a creator selects Anthropic (Claude), every text generation request made by the extension is sent to the Anthropic Messages API using the Claude model the creator has chosen.

YouTube Studio Assistant is developed by PT. Hoybee Creativs Digital, Indonesia. We also use Claude models in our day-to-day software development.

How to Use Claude in the Extension

Set up in a few minutes

1

Create an API Key

Create a Claude API key in the Claude Console (console.anthropic.com).

2

Select Anthropic (Claude)

Open the extension settings, choose Anthropic (Claude) as the provider, paste your key, pick a model and click Test Connection.

3

Generate in YouTube Studio

Edit any video in YouTube Studio and click Generate on the title, description, tags or translation panel.

Technical Details

  • Requests are sent from the extension's background service worker directly to https://api.anthropic.com/v1/messages.
  • The creator's API key is stored in the browser's extension storage. It is not sent to our servers.
  • The extension handles Claude API errors for rate limits, invalid keys, billing and temporary server issues, and shows a clear message to the creator.
// Simplified from the extension's background service worker
const response = await fetch('https://api.anthropic.com/v1/messages', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': settings.anthropicApiKey,
    'anthropic-version': '2023-06-01'
  },
  body: JSON.stringify({
    model: settings.anthropicModel || 'claude-sonnet-5',
    max_tokens: data.maxTokens || 800,
    messages: [{ role: 'user', content: data.prompt }]
  })
});
const result = await response.json();
return result.content[0].text;
