Berapa biaya extension ini?

Kamu bisa mencoba semua fitur GRATIS selama 7 hari. Setelah itu, upgrade ke lisensi lifetime (sekali bayar, akses selamanya). Beberapa provider AI seperti Pollinations.ai juga 100% gratis tanpa API key.

AI provider apa saja yang didukung?

Kami mendukung 6 provider AI: Pollinations.ai (100% gratis, tanpa API key), Groq (gratis & super cepat), OpenRouter (banyak model gratis), Google Gemini (ada tier gratis), OpenAI (kualitas terbaik, GPT-4o), dan DeepSeek (opsi berbayar paling terjangkau). Bisa diganti kapan saja.

Apakah data video saya aman?

Ya, 100% aman. Kami tidak menyimpan konten video atau API key kamu di server kami. Semua pemrosesan dilakukan langsung di browser.

Berapa banyak bahasa yang didukung?

Lebih dari 110 bahasa! Kamu bisa menerjemahkan judul, deskripsi, dan tag ke semua bahasa yang didukung YouTube secara otomatis.
